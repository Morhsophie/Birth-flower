THE THOUGHT BEHIND IT

Some flowers say
what words can't.

The cotton rose is a symbol of delicate beauty. This project turns that meaning into a small, personal birthday film: a flower appears, petals unfold, and a warm wish takes center stage.

It began as a gift for one person and became a way to explore how code can feel a little more human.

A closer look at how it was made ↓

THE PROCESS

Pixels, petals, Python.

A frame-by-frame animation built from an image, a few thoughtful details, and a script that brings it all together.

01

Draw every frame

Pillow layers the flower, type, and tiny details into each moment of the animation.

02

Bring it to life

ImageIO and FFmpeg turn those frames into a smooth, shareable video.

03

Make it personal

Change the name, date, flower, and meaning to make another greeting your own.

TAKE IT FOR A SPIN

Make a little
magic.

Run it locally to render the full birthday animation. Python 3.9 or newer is recommended.

YOUR TERMINAL
# Install the project dependencies
python -m pip install -r requirements.txt

# Render a birthday greeting
python birth_flower.py --name "Your Name"

The output video is saved as Cotton Rose_anim.mp4.
